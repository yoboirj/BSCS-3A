# Portfolio Hub Website

A modern, responsive **portfolio hub** that acts as a central directory linking out to multiple external portfolio sites.

## What’s included

- **Professional hero section** (name, role, short bio)
- **Portfolio Directory** rendered as responsive cards
- Each card includes:
  - **Project/Person name**
  - **Short description**
  - **Tech stack / category**
  - **Button/link** to an external portfolio website
- **Search** (filters by name, category, description, tech)

## Run it

This is a static site.

- Open `index.html` directly in your browser, or
- Use a local server (recommended) so everything behaves consistently:

```bash
# If you have Node installed:
npx serve .
```

## Edit the portfolio cards

Open `script.js` and update the `PORTFOLIOS` array (name, description, category, tech, url).
